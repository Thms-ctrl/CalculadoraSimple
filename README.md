# Calculadora!

Una calculadora de escritorio hecha con Python, para operaciones sencillas. ¡Una como las que te encuentras en la tienda!

## Tecnologías utilizadas
- Python
- Tkinter

## Operaciones de la calculadora
La calculadora es capaz de realizar:
- Suma
- Resta
- Multiplicación
- División

## Uso del programa

1. Descarga los archivos o copia el repositorio
2. Verifica que tengas Python instalado
3. Corre el archivo calculadora.py:
```bash
# ¡Verifica que estés en el directorio indicado!
python calculadora.py 
```
4. ¡Disfruta!
